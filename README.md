# Hisably v2 – Inventory, Invoices & Business

Mobile-first app for micro sellers (Pakistan, India, Bangladesh + English markets).

## Features

### Core
- Products with stock, cost price, barcode/QR scan
- Create invoices (stock auto-decreases)
- PDF download, Print, Share as Image (WhatsApp-friendly)
- Customers & Suppliers
- Custom-styled dropdowns (no system/native look)

### New
- **Searchable customer dropdown** – type to filter customers when creating invoices
- **Expense tracking** – rent, fuel, packaging, salaries, etc. with categories
- **Logo upload** – appears on PDF and image invoices
- **Profit & Reports** – Sales − Cost of Goods − Expenses = Net Profit
- Top selling products + expenses by category
- Full business settings (address, tax/NTN, currency, invoice prefix)

## How to use
1. Unzip and open `index.html` or host on GitHub Pages / Vercel / Netlify
2. Add to Home Screen on phone for app-like experience
3. Camera (barcode) needs HTTPS + permission

## Data
Stored only in the browser. Use **Export / Backup** regularly.
